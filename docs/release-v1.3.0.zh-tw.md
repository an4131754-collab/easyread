# EasyRead v1.3.0.zh-tw

繁體中文桌面版。安裝檔版號為 **1.3.0**。

## 新增與改善

- 閱讀区與原頁／筆記／問 AI 之間可拖曳調整寬度，雙擊分隔線恢復預設；保留窄視窗覆蓋模式。
- 整篇原文及譯文搜尋（Ctrl／⌘＋F）；隱藏語言命中時暫切對照，關閉搜尋還原顯示模式。
- 筆記可關聯圖表、收合預覽、改名與拖放；點卡片定位正文，明確按「編輯」修改。
- 自訂 API 接口可保存名稱與地址，金鑰依接口隔離，避免切換服務時沿用其他接口的金鑰。
- 損壞論文資料單篇隔離，其他文獻仍可使用；新增完整備份、手動恢復及 PDF 定位／裁圖更新入口。
- 新匯入改善跨頁／跨欄定位與圖表裁圖；舊論文不自動重算，手動更新前先完整備份，失敗時恢復。
- 翻譯 JSON 解析及取消／重試佇列修正；新增同時翻譯 1–4 篇設定，預設 1 篇，重啟後生效。
- 更新下載完成後等待使用者按「更新並重啟」；檢查失敗明確顯示，支援稍後重試。
- 修正服務重啟後舊分頁驗證碼過期造成重連循環，待存筆記可自動重送。

## 保留的客製功能

繁體中文介面、中英主次選擇、雙語螢光筆與取消標記保留筆記、問 AI 圖片／檔案附件、純照片訊息與多段 AI 回答引用追問。

## 更新方式

- Windows：下載 **EasyRead-Setup-1.3.0.exe**，或在既有桌面程式收到通知後下載更新。
- Linux：AppImage 支援程式內更新；其他執行方式請手動下載。
- macOS：首次採固定簽章的版本需手動下載安裝；後續版本必須沿用相同簽章身分。自簽憑證不等於 Apple 公證，系統可能提醒未識別開發者。

更新不搬移文獻庫或重設模型設定。舊論文 PDF 更新為手動操作，並保留完整備份；備份需額外磁碟空間。

## 驗證

此版核心程式通過 261 項 Python、26 項 Node、真實 Chrome 回歸，以及 Windows／macOS／Linux CI 建置和 frozen backend smoke。測試未呼叫真實模型。macOS／Linux 實機跨版本替換與真實 OneDrive 同步占用仍需實機驗證。
